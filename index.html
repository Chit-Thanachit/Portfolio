ผลงานโดดเด่น (Academic Projects)

Check-Air-Eco-Tips Mini-Project Mobile Application

มินิโปรเจกต์สำหรับรายวิชา Mobile Application Programming ที่พัฒนาขึ้นเพื่อแก้ปัญหาการติดตามคุณภาพอากาศในชีวิตประจำวัน โดยช่วยให้ผู้ใช้งานสามารถติดตามสถานการณ์คุณภาพอากาศ (AQI) ฝุ่นละอองขนาดเล็ก (PM2.5 และ PM10) และสภาพอากาศได้แบบ Real-time ดึงข้อมูลที่แม่นยำจากฐานข้อมูลภายนอกผ่าน RESTful API ครอบคลุมพื้นที่ทั้ง 77 จังหวัดทั่วประเทศไทย พร้อมระบบแนะนำการปฏิบัติตัวเพื่อรักษาสุขภาพ

รายละเอียดและฟีเจอร์หลักของระบบ:

  • Real-time AQI & Weather Tracking: ตรวจสอบค่า AQI, ฝุ่น PM2.5, PM10 อุณหภูมิ ความชื้น และความเร็วลม ได้แบบเรียลไทม์ครอบคลุม 77 จังหวัด
  • Dynamic UI Indicator: ตัวเลข AQI และสีของกรอบพื้นหลังจะเปลี่ยนสีให้อัตโนมัติตามระดับความรุนแรงของฝุ่น โดยอ้างอิงตามมาตรฐาน US AQI
  • Smart Eco-Tips: ระบบคำแนะนำการปฏิบัติตัวเพื่อดูแลสุขภาพและลดการสร้างมลพิษ โดยข้อความจะปรับเปลี่ยนอัตโนมัติตามระดับค่า AQI ในขณะนั้น
  • Auto Update & Pull-to-Refresh: มีระบบตั้งเวลาอัปเดตข้อมูลจาก API อัตโนมัติทุกๆ 1 ชั่วโมง และรองรับการดึงหน้าจอลงเพื่อรีเฟรชข้อมูลด้วยตัวเอง
  • User Authentication & Security: มีระบบหน้า Login พร้อมการตรวจสอบความถูกต้องของข้อมูล (Form Validation) และรองรับการซ่อนรหัสผ่านเพื่อความปลอดภัย

โครงงาน การพัฒนาเว็บแอปพลิเคชันเพื่อจองคิวใช้บริการสนามกอล์ฟ (กรณีศึกษา สนามกอล์ฟลานนา)(อยู่ระหว่างการพัฒนา)

โครงการพัฒนาระบบสารสนเทศแบบออนไลน์ครบวงจรในรูปแบบเว็บแอปพลิเคชันที่มีการแสดงผลแบบ Responsive Design รองรับการใช้งานทั้งบนคอมพิวเตอร์และสมาร์ทโฟนตลอด 24 ชั่วโมง วัตถุประสงค์เพื่อแก้ไขปัญหาและข้อจำกัดของระบบงานเดิม ปรับปรุงกระบวนการทำงานให้เป็นอัตโนมัติ ลดภาระงานจดบันทึกด้วยกระดาษ และเพิ่มความยืดหยุ่นในการให้บริการ

ขอบเขตการทำงานของระบบ (System Scope):

  • ระบบฝั่งผู้ใช้งาน (Client Side): ตรวจสอบสถานะคิวว่างแบบเรียลไทม์, จองวันและเวลาออกรอบ, เลือกแคดดี้, จองบริการเสริม (เช่น รถกอล์ฟ หรือการยืมอุปกรณ์) และระบบให้คะแนนรีวิวแคดดี้
  • ระบบปฏิบัติการหลังบ้าน (Back-Office System): ระบบสำหรับแคดดี้ พนักงาน ผู้จัดการ และผู้ดูแลระบบ เพื่อใช้บริหารจัดการข้อมูล ตารางงาน คิวการทำงาน และข่าวสารประชาสัมพันธ์

เทคนิคเชิงเทคนิคและการพัฒนาระบบ (Technical Highlights):

  • Database & Transaction Management: ออกแบบโครงสร้างตารางการจองและควบคุม Transaction อย่างกุม เพื่อป้องกันปัญหาคนแย่งจองคิวเวลาเดียวกัน (Race Condition) และป้องกันข้อมูลพังเวลาลบหรือแก้ไขประวัติการจอง
  • API & State Management: พัฒนา API สำหรับเชื่อมต่อกับแอปพลิเคชันมือถือ และใช้โครงสร้างแบบ StatefulWidget ควบคุม State ของหน้าจอฟอร์มจองคิวที่มีหลายขั้นตอน ไม่ให้ข้อมูลสูญหายระหว่างการกรอก
  • Role-Based Access Control (RBAC): ระบบจำกัดสิทธิ์การเข้าถึงและการจัดการข้อมูลของผู้ใช้งาน โดยแบ่งสิทธิ์ตามบทบาทอย่างชัดเจนถึง 6 บทบาท
  • Data Processing for Analytics: มีระบบประมวลผลและจัดเก็บข้อมูลสถิติคะแนน Scorecard อย่างเป็นระเบียบ เพื่อเตรียมพร้อมสำหรับการนำไปวิเคราะห์ต่อยอด เช่น การใช้ภาษา R ทำโมเดล Classification จัดกลุ่มลูกค้าเพื่อทำโปรโมชัน
